Árbol de experimentos

Cada nodo es una corrida, un control o una propuesta. Selecciona un nodo para ver resultados y cambios respecto a la referencia.

Verde: control con pesos congelados. Naranja: comparación con diferencias adicionales de entorno. Gris punteado: propuesta. Azul: comparación de resultados, sin relación de herencia.

Las flechas indican procedencia o referencia de comparación; no demuestran causalidad. Los modelos nuevos se entrenan desde cero. Validación fue usada para selección y no es prueba independiente. 2025 permanece reservada.
