# Etiquetado candidato: entrada a boxes

La etiqueta predice si se registra una visita a boxes dentro de las tres vueltas incluyendo la actual. No exige comprobar un cambio de neumáticos. `PitInTime` ancla el evento; `PitOutTime` lo empareja. Una entrada sin salida queda desconocida salvo confirmación FIA.

- Eventos detectados: 1779 (1715 clasificados; 64 sin resolver).
- Casos FIA revisados: 32; confirmados: 28.
- Etiquetas: 4817 positivas, 41361 negativas, 1819 desconocidas.
- Las etiquetas son candidatas; no se usaron 2024–2025 y no se entrenó ningún modelo.
