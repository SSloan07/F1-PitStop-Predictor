# Etiquetado candidato: entrada a boxes

La etiqueta predice si se registra una visita a boxes dentro de las tres vueltas incluyendo la actual. No exige comprobar un cambio de neumáticos. `PitInTime` ancla el evento; `PitOutTime` lo empareja. Una entrada sin salida queda desconocida salvo confirmación en un informe oficial.

- Casos revisados: 92; confirmados por FIA: 76; confirmados por cruce de fuentes: 16.
- Casos pendientes con diagnóstico local: 0 (`review_queue.csv`).
- Etiquetas: 4990 positivas, 41361 negativas, 1646 desconocidas.
- Las etiquetas son candidatas; no se usaron 2024–2025 y no se entrenó ningún modelo.
